## Why These 30 Were Selected

The set keeps all 10 questions already tested in Codex and adds 20 questions selected to provide:

- a 30-question bank for 10-question sessions
- all five Chapter 1 pilot areas
- easy, medium, and hard questions
- recall, understanding, recognition, application, analysis, misconception, and scenario formats
- repeated questions within selected concepts so same-concept remediation and mastery changes can be observed
- rule-and-exception content for saluting and obedience
- multiple difficulty levels within the same or closely related concepts

## Important Testing Note

Do not expect one ordinary user session to prove the 40/20/20/10/10 distribution.

Use several controlled test profiles or seeded mastery states:

1. fresh user with no history
2. user weak in two or three concepts
3. user with overdue mastered questions
4. user who repeatedly misses one concept
5. user with a sparse selection bucket

For each generated session, record:

- question external ID
- selection bucket
- mastery state
- due/overdue state
- selection reason
- fallback reason, if any

The original 10 questions retain their short explanations, memory aids, and visual metadata. The additional 20 use the same schema but leave optional memory and visual fields blank for now. Blank optional fields must not break the app.
