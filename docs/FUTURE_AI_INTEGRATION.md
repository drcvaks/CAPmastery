# Future AI Integration

AI is explicitly deferred until the reviewed non-AI question workflow, deterministic adaptive engine, security model, and family pilot are stable. No AI SDK, API key, prompt, endpoint, or generated-content pipeline belongs in Version 1.

## Later phases

1. Draft generation from approved, traceable source passages into structured draft records. Automated validation and human approval are mandatory; never auto-publish.
2. Personalized remediation grounded only in approved passages, using a student-safe identifier and minimal recent-error context. Store and label generated content separately; AI never changes mastery directly.
3. Quality analysis that flags ambiguity, duplicates, distractor problems, source mismatch, reading level, or multiple plausible answers. Humans decide.
4. Squadron capabilities only after family validation, privacy design, and permission testing.

## Future controls

Provider/model selection, data retention, child privacy, cost limits, prompt/version audit, source-grounding evidence, structured-output validation, moderation, failure handling, evaluation sets, and secret storage require explicit approval before implementation.
